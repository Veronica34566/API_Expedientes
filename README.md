# API REST - Sistema de Expedientes

## Descripción
Proyecto académico desarrollado con Python, Flask y MySQL.
Permite administrar expedientes mediante una API REST.

## Tecnologías utilizadas
- Python 3
- Flask
- MySQL
- phpMyAdmin
- Postman

## Operaciones CRUD

- POST: Registrar expedientes.
- GET: Consultar expedientes.
- PUT: Actualizar expedientes.
- DELETE: Eliminar expedientes.

## Base de datos
Nombre: sistema_expediente

## Ejecución
Instalar dependencias:

pip install -r requirements.txt

Ejecutar:

py app.py
